# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and evidence-oriented community.
Participants must be constructive, assume good faith, and avoid harassment,
discrimination, personal attacks, and publishing private information.

Report unacceptable behavior privately through the repository owner's GitHub
profile. Maintainers may edit, remove, or reject contributions that violate this
code. The full Contributor Covenant is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
